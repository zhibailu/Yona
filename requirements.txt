# 可选:记忆检索的语义路(BGE)
#
# 这两个包**故意不列在上面** —— 它们是可选的(用户 2026-09-21 拍板"甲")。
# 装了 → 记忆检索有语义路;没装 → 自动退化成只有关键词那一路,
# 产品照常能跑(core/embed.py 的 available() 只探路,不 import torch)。
#
#   pip install torch transformers
#
# 装完还要有模型(约 2.4 GB),默认**离线**加载(联网失败会让启动挂住,见下):
#   BAAI/bge-large-zh-v1.5
# 没装成 / 没模型时,启动日志里会有 [memory] 一行说明,**不会静默退化**。
#
# 实测(2026-09-21,RTX 5060 Ti / 24 线程 CPU):
#   暖机 4.18 s · 进程峰值 1894 MB(权重本身 1242 MB)
#   编码 147 ms/条(CPU,走真实补向量路径)· 10.9 ms/条(GPU,孤立循环)
#   冷启动把一张 315 条的老卡建成索引:CPU ≈ 46 s,全程在后台
#
# ⚠️ 不需要 GPU,也不需要 CUDA 版 torch:一条新记忆有 20 轮(≈60 秒)的余裕
#    等它的向量。有显卡是加分,不是前提。
# ⚠️ 也**别**为了"让路"去压 torch 线程数 —— 后台只在没人跑 turn 时才补,
#    压线程让不开任何东西,只会把索引建成拖慢 4 倍(605 ms/条 对 147 ms/条)。
